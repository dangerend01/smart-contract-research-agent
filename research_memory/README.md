# Research Memory

This directory stores machine-readable entries captured by the local research workflow and the aggressive lab mode.

Files include:

- hypothesis records generated from local contract analysis
- experiment records for reproducible local tests
- measured result summaries
- findings and rejected hypothesis indexes
- research log snapshots from local runs
- strategy-version artifacts such as strategy-v001 and strategy-v002
- cycle summaries from the self-improvement loop
- minimized counterexamples and learning notes

The contents are intentionally plain JSON and Markdown so a later AI or human agent can review the evidence trail without needing a special runtime.

The learning system records what was tested, what was learned, and how the strategy changed based on evidence. It does not rewrite historical results or silently discard prior observations.
